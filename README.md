# app-assets

社内向けアプリで使う、公開してよい画像（アイコンなど）の置き場。
アプリ本体のコードやデータは置かない。

| フォルダ | 用途 |
|---|---|
| `task-app/` | タスク管理アプリのアイコン（512 / 192 / 32px）と、PCでアイコン付きインストールするための入口ページ（GASの画面を埋め込むだけ。データは含まない） |
| `jimu-app/` | 工事事務アプリのアイコン（シマエナガ、512 / 192 / 32px）と、PC用の入口ページ（GASの画面を埋め込むだけ。データは含まない） |
| `dandori-app/` | 段取りナビ（新築の段取り）のアイコン（512 / 192 / 32px、会社ロゴなし）と、PC用の入口ページ（GASの画面を埋め込むだけ。データは含まない） |

画像のURL：`https://raw.githubusercontent.com/t-kimura-coder/app-assets/main/<フォルダ>/<ファイル名>`
